# PrairieLearn to Canvas Grade Sync Pipeline

## Overview

This ETL (Extract, Transform, Load) pipeline automates the grade synchronization process between PrairieLearn and Canvas. It parses PrairieLearn CSV exports, dynamically maps student identifiers to Canvas SIS User IDs, and executes a bulk payload update via the Canvas Submissions API.

## Prerequisites

- Python 3.x
- Required packages: `pandas`, `requests`
- A valid Canvas API token

For security purposes, the Canvas API token should not be hardcoded. Export it as an environment variable before execution:

```bash
export CANVAS_API_TOKEN="your_canvas_token_here"
```

## Input Data Format

The script is designed to process the `*_points_by_username.csv` file generated by PrairieLearn's assessment download feature. The pipeline auto-detects the score column based on the presence of the `Username` primary key.

## Usage

Run the script via the command line interface:

```bash
python sync_pipeline.py --csv <path_to_csv> --course <canvas_course_id> --assignment <canvas_assignment_id>
```

## Command Line Arguments

- `--csv` : (Required) Path to the PrairieLearn export CSV.
- `--course` : (Required) Target Canvas Course ID.
- `--assignment` : (Required) Target Canvas Assignment ID.
- `--domain` : (Optional) Canvas Domain URL. Defaults to `https://canvas.ucdavis.edu`.
- `--commit` : (Optional) Execution flag.

## Security & Testing (Dry-Run Mode)

By default, the script executes in **Dry-Run Mode**. It will extract the data, build the API payload, and validate the schema, but it **will not** dispatch the HTTP POST request to Canvas. This ensures data safety during testing.

To execute the actual database write operation to Canvas, append the `--commit` flag:

```bash
python sync_pipeline.py --csv ECS_32A_TEST26_Q2_points_by_username.csv --course 12345 --assignment 67890 --commit
```
